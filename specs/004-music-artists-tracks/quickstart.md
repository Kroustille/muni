# Quickstart: Music artists and tracks (004)

**Prerequisites**: Features **002** and **003** complete (X1).

## Manual quick-add

1. Quick-add → track → enter title + artist → save.
2. Quick-add has **no** catalog search button (MU4).

## Catalog on list

1. Open **Tracks** list → **Rechercher** → pick recording → preview → save.
2. Repeat on **Artists** list for artist MBID.

## External links

1. On detail, tap **Ouvrir sur Spotify** → external search with prefilled query.
2. Paste Spotify URL on preview → save → tap opens URL.

## Dedupe

1. Search same recording twice → one row updated.
